# The starting point

`tuto-hello-world-deep-learning-medical-imaging.ipynb` is a transcription with
Keras, written in April 2021, of the tutorial by Lakhani et al. (Journal of
Digital Imaging, 2018, <https://doi.org/10.1007/s10278-018-0079-6>). It is
kept as it was published, except that its outputs were cleared: they
contained two radiographs from the dataset, which is not stored in this
repository.

The notebook was written for TensorFlow 2.4 and Keras 2. Nothing in it says
so: the versions of the libraries it ran with were never written down, and the
images have to be downloaded and unzipped by hand next to it. The following
steps of the repository start from there.
